## 🔧 TECHNICAL IMPLEMENTATION

### **Current Working Code** (as of Nov 20, 2025)

```python
ANALYTICS_TRACKING_CODE = """
<!-- Privacy-friendly analytics by Plausible - Injected into HEAD via JavaScript -->
<script>
(function() {
  // Inject Plausible script into HEAD (required for proper tracking)
  if (!document.querySelector('script[src*="plausible.io"]')) {
    var script = document.createElement('script');
    script.defer = true;  // Use defer instead of async for proper loading
    script.setAttribute('data-domain', 'familyforecast.ai');  // CRITICAL: Domain to track
    script.src = 'https://plausible.io/js/pa-3npHKPHg2kmQuG1mgMbMw.js';
    document.head.appendChild(script);

    // Initialize Plausible
    window.plausible = window.plausible || function() {
      (window.plausible.q = window.plausible.q || []).push(arguments);
    };
  }
})();
</script>
"""
```

### **Why This Implementation?**

1. **Dynamic HEAD Injection**
   - Streamlit normally injects HTML into `<body>`, not `<head>`
   - Plausible requires script in `<head>` for proper detection
   - We use JavaScript to dynamically append to `document.head`

2. **Deferred Loading**
   - `script.defer = true` ensures script executes after DOM is ready
   - Better than `async` for analytics scripts that need the DOM

3. **Duplicate Prevention**
   - Check `!document.querySelector('script[src*="plausible.io"]')`
   - Prevents multiple script injections if page re-renders

4. **Custom Proxy Script**
   - Filename `pa-3npHKPHg2kmQuG1mgMbMw.js` is a custom proxy
   - Helps bypass ad blockers that block `script.js`
   - Generated by Plausible when you enable proxy mode

## 🐛 COMMON ISSUES & SOLUTIONS

### **Issue 1: "We couldn't detect Plausible on your site"**

**Symptoms:**
- Plausible verification fails
- No visitor data appearing
- Script loads but doesn't track

**Root Cause:**
- Missing `data-domain` attribute
- Script can't identify which domain to track

**Solution:**
```javascript
script.setAttribute('data-domain', 'familyforecast.ai');  // Must be present!
```

**How to Verify Fix:**
1. Open browser DevTools (F12)
2. Go to Elements tab
3. Find the Plausible script in `<head>`
4. Verify it has `data-domain="familyforecast.ai"` attribute

---

### **Issue 2: Script Not Loading**

**Symptoms:**
- No network request to plausible.io
- `window.plausible` is undefined
- Console errors about missing script

**Root Causes:**
- Ad blocker blocking the script
- Network/firewall blocking plausible.io
- Script URL is incorrect

**Diagnosis Steps:**
```javascript
// Open browser console and run:
console.log(window.plausible);  // Should show function, not undefined

// Check if script is in DOM:
console.log(document.querySelector('script[src*="plausible.io"]'));  // Should show element

// Check network:
// DevTools → Network tab → Filter "plausible" → Should see request with Status 200
```

**Solutions:**
- **Ad Blocker:** Custom proxy script helps bypass (already implemented)
- **Firewall:** Whitelist `plausible.io` domain
- **Wrong URL:** Verify script URL matches Plausible dashboard

---

### **Issue 3: Tracking Works Locally But Not in Production**

**Symptoms:**
- Works on localhost
- Fails on familyforecast.ai

**Root Cause:**
- Domain mismatch in `data-domain` attribute

**Solution:**
Ensure `data-domain` exactly matches your production domain:
```javascript
// Correct for production:
script.setAttribute('data-domain', 'familyforecast.ai');

// NOT:
script.setAttribute('data-domain', 'www.familyforecast.ai');  // Wrong!
script.setAttribute('data-domain', 'localhost');  // Wrong!
```

---

### **Issue 4: Double Counting / Multiple Pageviews**

**Symptoms:**
- One visit shows as 2-3 pageviews
- Duplicate events

**Root Cause:**
- Script injected multiple times due to Streamlit re-renders

**Solution:**
Our duplicate prevention check (already implemented):
```javascript
if (!document.querySelector('script[src*="plausible.io"]')) {
  // Only inject if not already present
}
```
